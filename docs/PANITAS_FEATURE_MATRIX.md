## 3. Conclusiones de la matriz

1. **La base administrativa es igual para ambos planes** — no se castiga al plan base con menos módulos de gestión.
2. **La diferenciación es IA comercial + comunicación**: todo lo que implica "conversar con clientes y vender más" es PLUS.
3. **Nada automático de mensajes** en ningún plan: el copiloto siempre sugiere.
4. **El plan base ya tiene IA consultiva** — es parte del valor central, no un add-on.
5. **Límites técnicos** (productos, cajas, usuarios, consultas IA) refuerzan el upgrade con contexto, no con bloqueos bruscos.
